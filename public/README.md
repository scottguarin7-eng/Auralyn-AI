# Auralyn

Auralyn is a futuristic AI workspace powered by Gemini.

## Features

- Liquid-glass futuristic UI
- Auralyn AI chat
- Gemini Flash API integration
- Server-side API key handling
- Animated fusion core
- Quick prompts
- Copy AI responses
- Temperature control
- Workspace navigation
- Responsive mobile layout
- Vercel-ready structure
