# Auralyn

Auralyn is a futuristic AI workspace for thinking, learning, researching, coding, and creating.

## Features

- Liquid-glass interface
- Animated Auralyn fusion core
- Gemini Flash integration
- Server-side API key handling
- Responsive dashboard
- Quick prompts
- Conversation reset
- Copy AI responses
- Temperature control
- Mobile navigation
- Keyboard shortcuts
- Vercel-ready deployment

## Tech stack

- Next.js
- TypeScript
- React
- Tailwind CSS
- Google Gen AI SDK
- Lucide React
- Vercel
